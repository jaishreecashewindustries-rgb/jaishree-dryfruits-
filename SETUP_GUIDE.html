Step 1

🔥 Create Firebase Project

  1. Go to https://console.firebase.google.com
  2. Click "Add Project"
  3. Name it: jaishree-dryfruits
  4. Enable Google Analytics (optional) → Click "Create Project"

Enable 3 Firebase Services:

🔐 Authentication

  • Build → Authentication → Get Started
  • Enable Email/Password provider
  • Enable Google provider
  • Authorized domains → Add localhost (for testing) and your domain

🗄️ Firestore Database

  • Build → Firestore Database → Create database
  • Select: Production mode
  • Region: asia-south1 (Mumbai — best for India)

📁 Storage

  • Build → Storage → Get started → Production mode

Get Firebase Config Keys:

  1. Click the ⚙️ gear icon → Project Settings
  2. Scroll to "Your apps" → Click Add Web App (</> icon)
  3. App name: jaishree-web → Register
  4. Copy the firebaseConfig object — you'll need this in Step 2
Step 2

🔧 Configure Your Environment File

In the project folder, find the file .env.example.

Create a new file called .env (just rename the copy) and fill in your Firebase values:

REACT_APP_FIREBASE_API_KEY=AIzaSyXXXXXXXXXXXXXXX
REACT_APP_FIREBASE_AUTH_DOMAIN=jaishree-dryfruits.firebaseapp.com
REACT_APP_FIREBASE_PROJECT_ID=jaishree-dryfruits
REACT_APP_FIREBASE_STORAGE_BUCKET=jaishree-dryfruits.appspot.com
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=1234567890
REACT_APP_FIREBASE_APP_ID=1:1234567890:web:abc123def456
💡 Where to find these? Firebase Console → Your Project → ⚙️ Project Settings → Your Apps → SDK setup and configuration → Config
⚠️ Never share your .env file or commit it to GitHub. It contains secret keys!

Update WhatsApp Number:

Open src/utils/helpers.js and change line 3:

export const WHATSAPP_NUMBER = "919876543210";
// Format: 91 (India code) + your 10-digit mobile number
// Example: 919876543210 for number 98765 43210

Update Firebase Project ID:

Open .firebaserc and change:

{ "projects": { "default": "jaishree-dryfruits" } }
// Replace "jaishree-dryfruits" with your actual Firebase Project ID
Step 3

🖥️ Install & Run Locally (Test First)

📌 Requirement: Install Node.js from nodejs.org (download the LTS version)

Open your Terminal (Mac) or Command Prompt (Windows), go to the project folder:

# Go into the project folder
cd /Users/YourName/Downloads/jaishree-v9

# Install all packages (only needed once)
npm install

# Start the local development server
npm start

Your website will open automatically at http://localhost:3000 🎉

Step 4

👑 Make Yourself Admin

After running the website, register/login with your email. Then:

  1. Go to Firebase Console → Firestore Database
  2. Click on the users collection
  3. Find your document (look for your email)
  4. Click on the document → Click the role field → Edit it
  5. Change "customer" → "admin" → Save
  6. Refresh your website → Go to yourwebsite.com/admin
✅ Now you can access the full Admin Dashboard with Products, Orders, Customers, Reviews, Colors management!
Step 5

🚀 Deploy Live to Firebase Hosting

Run these commands in your Terminal one by one:

# 1. Install Firebase tools (one time only)
npm install -g firebase-tools

# 2. Login to Firebase (opens browser for Google login)
firebase login

# 3. Build the production version of your website
npm run build

# 4. Deploy Firestore security rules
firebase deploy --only firestore:rules

# 5. Deploy your website live
firebase deploy --only hosting
🌐 After deployment, your website is LIVE at:
https://jaishree-dryfruits.web.app
(Replace with your actual project ID)
Step 6

🌐 Connect Custom Domain (Optional)

  1. Firebase Console → Hosting → Add custom domain
  2. Enter your domain: www.jaishreegryfruits.com
  3. Firebase gives you DNS records (TXT + A records)
  4. Go to your domain registrar (GoDaddy / Namecheap etc.) → Add those DNS records
  5. Wait 24–48 hours → SSL certificate is auto-applied ✅
Step 7

📦 Add Your Real Products

Easiest way — Admin Dashboard:

  1. Login as admin on your website
  2. Go to /admin/products
  3. Click "Add Product"
  4. Fill in: Name, Category, Description, Badge
  5. Add product image URLs (see image hosting below)
  6. Add variants: 250g → ₹349, 500g → ₹649, 1kg → ₹1199
  7. Click Save Product ✅

Free Image Hosting Options:

  • Firebase Storage — Upload in Firebase Console → Storage → Copy URL
  • Cloudinary.com — Free 25GB, best quality
  • ImgBB.com — Free, unlimited uploads

Security

🔒 Security Checklist Before Going Live

  • Firestore rules deployed (firebase deploy --only firestore:rules)
  • .env file added to .gitignore — never commit to GitHub
  • Admin role only assigned to your email account
  • Firebase Auth: Remove localhost from authorized domains after launch
  • HTTPS enabled (automatic with Firebase Hosting ✅)
